# Generated example media

These are AI-generated source images, SAM3 mask unions and Blender renders of
generated meshes from the sweeping comparison. They are example outputs, not
model weights or photographs of an identified person.

The repository's MIT code licence does not assign a blanket licence to these
generated outputs. Applicable upstream model/output terms and input rights
remain separate; see [third-party terms](../../../THIRD_PARTY.md).
Models are credited to Black Forest Labs, Meta and Microsoft / TRELLIS.2 authors.

PNG descriptive/EXIF metadata was removed to avoid publishing local filesystem
paths. Pixel data and colour-management chunks are unchanged; there was no
cropping, retouching or enhancement. Original and published file hashes are in
[provenance.json](provenance.json), along with the prompt, seed, mask queries,
available model/source revisions and recorded camera settings. No environment
configurations, private paths, model weights, GLBs or Blender files are included.
